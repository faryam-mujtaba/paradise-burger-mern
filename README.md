# Paradise Burger MERN

Paradise Burger is a MERN stack restaurant ordering and delivery management system.

## Main Features

- Customer registration and login
- Mobile number verification
- Menu browsing
- Cart and checkout
- Cash on Delivery order placement
- Admin order management
- Rider assignment
- Rider delivery updates
- Responsive design for mobile, tablet, laptop, desktop, and large restaurant screens

## Technology Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT Authentication
- MVC Architecture
